# The Fall of Caine · Cold Open (test build)

The playable cold open: Bernard's chase through Coquina City, ending in the bullet-time shot, the starring montage and the title.

Open `index.html` through any static server, or turn on GitHub Pages (Settings → Pages → deploy from `main`).

## Controls
- **WASD / arrow keys** (or drag on a phone): run
- **Space:** flip over obstacles
- **Esc / Skip:** jump ahead
