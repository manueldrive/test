## Crayon Shark Lagoon (`shark-lagoon/`)

An aquarium where kids' drawings become sharks. Color a shark skin on paper, take a photo with **Scan a drawing**, name it, and it swims into the tank. You can also **Draw on screen**. Tap a shark to make it zoom.

- Open `shark-lagoon/index.html` in a browser. It's a single file with no build step.
- Sharks are saved in that browser's local storage, so they stay on that one device only.
