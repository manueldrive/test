# Red String · Prototype (test build)

A noir party murder-mystery game, playing a test case adapted from *The Adventure of the Speckled Band* (Arthur Conan Doyle, 1892, public domain).

- `index.html`: the clickable game prototype: lobby, briefing, 3 timed rounds (files, evidence, murder board, suspects), lineup vote and verdict. The other three detectives are simulated. **SKIP ▸** by the timer is for testing only.
- `evidence/`: the 3D evidence viewer (three.js). Spin each item and tap anything that looks wrong to find hidden details.

Open `index.html` through any static server, or turn on GitHub Pages (Settings → Pages → deploy from `main`).
